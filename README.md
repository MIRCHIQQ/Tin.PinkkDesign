# Tin.PinkkDesign: портфолио

Одностраничный сайт-портфолио web-разработчика Антона: МИС «Мегаклиника» на главном экране, сайты «Норма» и «Ёлочный Бал», дизайнерские работы, блок «Обо мне» и контакты.

Без сборки и зависимостей: чистые HTML, CSS и JavaScript.

## Структура

```
portfolio/
├── index.html        разметка и тексты
├── css/style.css     стили, цвета лежат в :root
├── js/main.js        ленты на фоне, курсор, меню МИС, вкладки экранов, просмотр графики, финальная панель
├── img/              скриншоты МИС и дизайнерские работы (webp)
├── favicon.svg
└── .nojekyll         нужен для GitHub Pages
```

## Запуск у себя

Откройте `index.html` в браузере. Или запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

и откройте http://localhost:8000.

## Публикация на GitHub Pages

```bash
cd portfolio
git init
git add .
git commit -m "Портфолио"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<репозиторий>.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. Через минуту-две сайт появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Если назвать репозиторий `<ваш-логин>.github.io`, сайт откроется прямо по адресу `https://<ваш-логин>.github.io/`.

## Контакты и адрес в соцсетях

- **Контакты** лежат в блоке `<div class="contacts">` в конце `index.html`: Telegram `@Tin_Pinkk` и почта. Чтобы поменять, исправьте текст и значение `data-copy` у кнопки «Копировать».
- **Карточка при отправке ссылки (по желанию).** Добавьте в `<head>` теги `<meta property="og:image" content="https://.../img/mis-dark.webp">` и `<meta property="og:url" content="...">` с полными адресами.

## Как поменять

- **Цвет акцента:** переменная `--lime` в начале `css/style.css`. Цвет текста на акцентной кнопке: `--lime-ink`.
- **Шрифты:** Onest, Cormorant Garamond, JetBrains Mono и Yeseva One подключаются с Google Fonts в `<head>`. Без интернета страница откроется на системных шрифтах.
- **Дизайнерские работы:** файлы в `img/` (`d-*.webp`). Чтобы добавить работу, скопируйте блок `<figure class="work">` в секции `#design`. В `--r` укажите отношение ширины к высоте картинки.
- **Цифры и навыки:** блок `#about` (`data-count` у счётчиков, список `.skills`).
- **Меню МИС (было и стало):** массив `G` и объект `ROLES` в начале блока «меню МИС» в `js/main.js`.

## Производительность

Фон со световыми лентами сам подбирает качество под компьютер. Если кадры начинают тормозить, страница по шагам упрощается: сначала убирается свечение, затем остаются редкие линии с 30 кадрами в секунду, и в самом крайнем случае лента становится неподвижной. Когда страница прокручена ниже первого экрана или вкладка скрыта, анимация останавливается.

Чтобы проверить режимы вручную, добавьте к адресу `?fx=0` (полное качество), `?fx=1`, `?fx=2` или `?fx=3` (неподвижный фон).

## Совместимость

Современные Chrome, Safari, Firefox и Edge. Учитывается `prefers-reduced-motion`: при включённой настройке «уменьшить движение» ленты, анимации и растущая панель отключаются. Страница работает на телефоне от 360 px.
